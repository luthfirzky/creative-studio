# Creative Studio — Landing Page

Situs statis (HTML + CSS + JavaScript murni), tanpa proses build.

## Struktur
- `index.html` — struktur & konten halaman
- `css/style.css` — tampilan, animasi, dan aturan responsive
- `js/main.js` — interaksi (menu mobile, filter portfolio, slider testimoni, form)
- `favicon.svg` — ikon tab browser

## Menjalankan di komputer
    npx serve .

## Deploy
Push ke GitHub, lalu import repository di vercel.com (Framework Preset: Other).
